Effect school

How to name the look you want, and what will actually run on thealphasignature.com (Hostinger). This page is teaching only. The code index stays as it is.

The short rule for your live domain

Works if the phone draws it: HTML, CSS, SVG, SVG filters, CSS animations, and plain JavaScript files you upload into public_html.

Does not work as a page effect: C++, Java, a native SDK, Drizzle, or a Node server process. Those are not browser paints. Hostinger will not run them just because the file is sitting next to login.php.

thealphasignature.com is a PHP site (login.php). Shared PHP hosting serves files. It does not compile C++ or keep a Java or Node process alive unless you add a separate Node Web App on a Business or Cloud plan, or a VPS.

SVG filter glow — the pieces

A glow is not one property. It is a pipeline. You blur a copy, color that copy, then lay the sharp original on top. The glow object is separate from the letter fill, which is what you asked for on the city cards.

  1. feGaussianBlur — the soft halo. stdDeviation is the spread. 2 is a pin light. 8 is a bloom.
  2. feMorphology operator="dilate" — grows the shape before the blur, so the glow is an outline, not a fill of the letter.
  3. feFlood + feComposite — paints the halo one color (gold or green) instead of the text color.
  4. feColorMatrix — recolors or fades the blur. Use this for a low-opacity gold wash.
  5. feOffset — moves the blur. Zero offset is a halo. A few pixels down is a drop shadow.
  6. feMerge — stacks the glow under the original so letters stay sharp.
  7. feDropShadow — shorthand for offset + blur + color. Less control than the stack.
  8. feTurbulence + feDisplacementMap — ripples the glow. Pretty, expensive on a phone.
  9. feSpecularLighting / feDiffuseLighting — fake metal highlight. Heavy. Use once, not on every card.
  10. feComponentTransfer — curves the alpha so the glow falls off instead of looking muddy.
  11. feConvolveMatrix — a tiny sharpen or emboss kernel. Easy to wreck text with this.

x/y/width/height must be larger than the shape or the glow gets clipped. That is the usual "my glow disappeared" bug.

CSS effects that also work on the domain

Use these when you do not need a separate glow object. They are cheaper than SVG filters on a long list of city cards.

  • text-shadow stacked, blur only, no offset — outward halo. Letter fill stays solid. This is what the code index uses.
  • box-shadow inset rings — the dark / gold / green pin stack.
  • linear-gradient / radial-gradient — washes behind a title.
  • filter: drop-shadow() — follows the alpha of the whole element, including text. Good on a button, muddy if stacked on body copy.
  • backdrop-filter: blur() — frosted glass. Works in current Safari and Chrome. Costs GPU. Do not put it on every card.
  • mix-blend-mode — screen or plus-lighter for a real light bloom. Can wash out black text. Test on the phone in daylight.
  • @keyframes and transition — fade, slide, pulse a glow. Works. Prefer opacity and transform. Animating blur or box-shadow on 15 cards will stutter.
  • conic-gradient — metallic spin on a border. Works. A spinning border on every card is noise.

Will not run as a page effect on thealphasignature.com

  • C++ glow library, Unreal, a native binary. Hostinger shared PHP has no compiler and will not execute it.
  • Java Swing, JavaFX, old applets. Browsers dropped applets. No Java runtime on this host.
  • Node server, Express, a websocket glow engine. Not on the PHP public_html. Only if you add a Hostinger Node Web App (Business or Cloud plan) or a VPS, as a separate app.
  • Drizzle. Database ORM. It does not paint pixels.
  • iOS / Android SDK effects. Those live in an app, not in login.php.
  • SMIL inside SVG. Chrome support is uneven. Use CSS animation instead.
  • Heavy WebGL on the sales map. It can load, then the phone gets hot and Safari kills the tab.

GitHub Pages (this file) and Hostinger public_html follow the same rule: if the browser can draw it from HTML, CSS, and SVG, it works. If it needs a compiler or a long-running server, it does not.
